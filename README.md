## Цель проекта

Настроить сетевые устройства и прикладные протоколы, разобрать принципы сетевого взаимодействия и проанализировать передаваемые данные на уровне сетевых пакетов.

В рамках проекта настроены статическая маршрутизация, NTP, DNS, DHCP и SSH, проверена работоспособность сервисов и исследован соответствующий сетевой трафик в Wireshark.

## Контекст

Работа выполнялась в изолированной виртуальной лаборатории на базе Ubuntu 22.04 в VirtualBox. Для моделирования сетевой инфраструктуры использовался GNS3 с сетевыми устройствами Cisco 3745.

## Окружение и инструменты

| Компонент | Назначение |
|---|---|
| Ubuntu 22.04 | Операционная система |
| VirtualBox | Виртуализация лабораторного окружения |
| GNS3 | Эмуляция сетевой инфраструктуры |
| Cisco 3745 | Сетевые маршрутизаторы |
| Wireshark | Захват и анализ сетевого трафика |

## Ход работы

> Подробный отчёт (конфигурации, результаты проверок, скриншоты): [docs/report.md](docs/report.md)

### 1. Static Routing

Настроена статическая маршрутизация между тремя последовательно соединёнными маршрутизаторами Cisco: IP-адресация интерфейсов и статические маршруты для связи между удалёнными сегментами.

Связность проверена с помощью ICMP (ping), прохождение пакетов исследовано в Wireshark.

### 2. NTP

Настроены NTP-сервер на одном устройстве и NTP-клиент на другом.

Проверена синхронизация времени между устройствами. В Wireshark исследован NTP-трафик: структура пакетов и временные метки.

### 3. DNS

Настроен DNS-сервер на сетевом устройстве, добавлена запись для тестового доменного имени, клиент настроен на использование этого сервера.

Проверено разрешение имени в IP-адрес, в Wireshark проанализированы DNS-запросы и ответы.

### 4. DHCP

Настроен DHCP-сервер на маршрутизаторе Cisco для автоматической выдачи IP-адресов.

Подключён виртуальный компьютер VPCS, проверены получение сетевых параметров и связность. В Wireshark исследованы DHCP- и ICMP-пакеты, включая последовательность DHCP DORA.

### 5. SSH

Настроен SSH на маршрутизаторе Cisco: создан пользователь и сгенерированы RSA-ключи для защищённого удалённого доступа.

Проверена доступность TCP-порта 22 и выполнено подключение к устройству по SSH. В Wireshark исследованы TCP Three-Way Handshake и обмен при установлении SSH-соединения.

Дополнительно разобраны различия между Telnet и SSH с точки зрения безопасности передачи данных: незащищённое и защищённое взаимодействие.

## Анализ сетевого трафика и применение в SOC

Понимание нормального поведения сетевых протоколов лежит в основе анализа сетевой активности в SOC.

В проекте исследованы следующие типы сетевого взаимодействия:

| Протокол | Изучаемые особенности |
|---|---|
| ICMP | Проверка сетевой связности и обмен Echo Request / Echo Reply |
| NTP | Синхронизация времени и структура NTP-пакетов |
| DNS | Запросы и ответы, разрешение доменных имён |
| DHCP | Автоматическая выдача IP-адресов и последовательность DORA |
| TCP | Установление соединения и TCP Three-Way Handshake |
| SSH | Защищённое удалённое подключение |
| Telnet | Незашифрованное сетевое взаимодействие |

Эти знания применимы при исследовании сетевых событий, анализе PCAP-файлов и поиске отклонений от нормального поведения протоколов.

Внедрение SIEM, IDS/IPS и разработка правил обнаружения угроз в рамках данного проекта не выполнялись.

## Результаты

- Настроена статическая маршрутизация между сетевыми сегментами.
- Настроена синхронизация времени с использованием NTP.
- Настроено разрешение доменных имён с использованием DNS.
- Настроена автоматическая выдача IP-адресов через DHCP.
- Настроен удалённый доступ к сетевому устройству через SSH.
- Трафик каждого сервиса захвачен и разобран в Wireshark, включая DHCP DORA и TCP Three-Way Handshake.
- Изучены различия между Telnet и SSH с точки зрения защиты передаваемых данных.
- Результаты сохранены в виде проектов GNS3 и PCAP-дампов.
