# Network Services and Traffic Analysis

Практическая настройка сетевых протоколов и анализ сетевого трафика с использованием GNS3, Cisco IOS и Wireshark.

## Контекст

Работа выполнялась в изолированной виртуальной лаборатории на базе Ubuntu 22.04 в VirtualBox. Для моделирования сетевой инфраструктуры использовался GNS3 с сетевыми устройствами Cisco 3745.

## Цель проекта

Получить практический опыт настройки сетевых устройств и прикладных протоколов, изучить принципы сетевого взаимодействия и научиться анализировать передаваемые данные на уровне сетевых пакетов.

В рамках проекта я выполнил настройку статической маршрутизации, NTP, DNS, DHCP и SSH, проверил работоспособность настроенных сервисов и исследовал соответствующий сетевой трафик в Wireshark.

## Ход работы

### 1. Static Routing

Настроил статическую маршрутизацию между тремя маршрутизаторами Cisco, соединёнными последовательно.

Настроил IP-адресацию интерфейсов и статические маршруты для обеспечения взаимодействия между удалёнными сетевыми сегментами.

Проверил связность с помощью ICMP (ping) и исследовал прохождение пакетов в Wireshark.

### 2. NTP

Настроил NTP-сервер на одном из сетевых устройств и NTP-клиент на другом.

Проверил синхронизацию времени между устройствами и исследовал NTP-трафик в Wireshark, включая структуру передаваемых пакетов и временные метки.

### 3. DNS

Настроил DNS-сервер на сетевом устройстве, добавил DNS-запись для тестового доменного имени и настроил клиент для использования данного сервера.

Проверил разрешение доменного имени в IP-адрес и проанализировал DNS-запросы и ответы в Wireshark.

### 4. DHCP

Настроил DHCP-сервер на маршрутизаторе Cisco для автоматической выдачи IP-адресов клиентам.

Подключил виртуальный компьютер VPCS, проверил получение сетевых параметров и сетевую связность.

Исследовал DHCP- и ICMP-пакеты в Wireshark, включая последовательность DHCP DORA.

### 5. SSH

Настроил SSH на маршрутизаторе Cisco, создал пользователя и сгенерировал RSA-ключи для организации защищённого удалённого доступа.

Проверил доступность TCP-порта 22 и выполнил подключение к сетевому устройству по SSH.

В Wireshark исследовал TCP Three-Way Handshake и сетевой обмен при установлении SSH-соединения.

Дополнительно разобрал различия между Telnet и SSH с точки зрения безопасности передачи данных, включая особенности незашифрованного и защищённого сетевого взаимодействия.

## Анализ сетевого трафика и применение в SOC

Понимание нормального поведения сетевых протоколов является одной из основ анализа сетевой активности в SOC.

В рамках проекта я получил практический опыт исследования следующих типов сетевого взаимодействия:

| Протокол | Изучаемые особенности |
|---|---|
| ICMP | Проверка сетевой связности и обмен Echo Request / Echo Reply |
| NTP | Синхронизация времени и структура NTP-пакетов |
| DNS | Запросы и ответы, разрешение доменных имён |
| DHCP | Автоматическая выдача IP-адресов и последовательность DORA |
| TCP | Установление соединения и TCP Three-Way Handshake |
| SSH | Защищённое удалённое подключение |
| Telnet | Незашифрованное сетевое взаимодействие |

Полученные знания могут применяться при исследовании сетевых событий, анализе PCAP-файлов и поиске отклонений от нормального поведения сетевых протоколов.

Внедрение SIEM, IDS/IPS и разработка правил обнаружения угроз в рамках данного проекта не выполнялись.
